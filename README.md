# ML Network Intrusion Detector

## Project Description
This project implements a Machine Learning model using Scikit-Learn to detect and classify network anomalies and malicious intrusions based on network traffic features.

## Technologies Used
- Python 3.x
- Pandas & NumPy (Data Processing)
- Scikit-Learn (Machine Learning)

## How to Run
1. Install dependencies:
   `pip install -r requirements.txt`
2. Open `Bhumi_NetworkIntrusionDetector.ipynb` in Google Colab or Jupyter Notebook.
3. Run all cells sequentially to train and evaluate the model.

## Results
The Random Forest Classifier achieves high precision and accuracy in distinguishing normal traffic from network anomalies.
